## Deskripsi Tugas

### 1. Program Penghitung BMI
File: `tugas1_bmi.py`

Program digunakan untuk menghitung Body Mass Index (BMI) berdasarkan berat badan dalam kilogram dan tinggi badan dalam meter. Hasil perhitungan dikategorikan menjadi berat badan kurang, normal, berlebih, dan obesitas menggunakan percabangan if-elif-else.

Cara menjalankan:
```bash
python tugas1_bmi.py
```

### 2. Program Pengelolaan Data Nilai Mahasiswa
File: `tugas2_nilai_mahasiswa.py`

Program menggunakan list dan dictionary untuk menyimpan data minimal lima mahasiswa. Program menghitung nilai akhir berdasarkan bobot UTS 30%, UAS 40%, dan tugas 30%, menentukan grade A-E, menampilkan tabel nilai, serta mencari nilai tertinggi dan terendah.

Cara menjalankan:
```bash
python tugas2_nilai_mahasiswa.py
```

### 3. Modul Matematika Python
File: `math_operations.py` dan `main.py`

Program menggunakan modul matematika kustom untuk menghitung luas dan keliling persegi, persegi panjang, dan lingkaran. Selain itu, terdapat fungsi konversi suhu Celsius ke Fahrenheit dan Kelvin.

Program menerapkan dua metode import, yaitu `import math_operations` dan `from math_operations import ...`.

Cara menjalankan:
```bash
python main.py
```
