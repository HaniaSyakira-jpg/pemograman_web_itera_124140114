## Deskripsi
Proyek ini merupakan praktikum JavaScript Next Gen yang mempelajari fitur modern JavaScript melalui demo interaktif berbasis web.

## Materi yang Dipelajari
1. Let dan Const
2. Arrow Functions
3. Template Literals
4. Destructuring
5. Spread dan Rest
6. Default Parameters
7. Classes dan Inheritance
8. Enhanced Object Literals
9. Modern Array Methods
10. Advanced Arrays
11. Promises
12. Async/Await

## Teknologi
- HTML5
- CSS3
- JavaScript ES Modules
- Tailwind CSS

## Cara Menjalankan
1. Buka folder `project-js-nextgen` di Visual Studio Code.
2. Jalankan `index.html` menggunakan Live Server.
3. Klik **Run Demo** untuk menampilkan hasil.
4. Klik **Clear Output** untuk membersihkan hasil demo.

## Struktur Folder
- `index.html`: struktur halaman web.
- `css/style.css`: styling halaman.
- `js/main.js`: pengaturan interaksi dan output.
- `js/app.js`: implementasi demo JavaScript.
- `js/modules/data.js`: data contoh.
- `js/modules/utils.js`: fungsi bantuan.
- `screenshot/`: dokumentasi hasil praktikum.
